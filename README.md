# Iran Conflict Detector

An AI-powered geopolitical risk monitoring platform designed to track, analyze, and summarize developments related to Iran and surrounding regional tensions in real time.

## Overview

Iran Conflict Detector uses artificial intelligence to aggregate news, detect emerging escalation patterns, analyze geopolitical signals, and generate concise situation summaries for researchers, analysts, journalists, and curious observers.

The platform is built to transform large volumes of fragmented information into structured insights that are easier to understand and monitor.

## Features

* Real-time monitoring of geopolitical developments
* AI-powered conflict and escalation analysis
* Breaking news aggregation from multiple sources
* Smart summarization of complex events
* Sentiment and risk-level detection
* Timeline-based event tracking
* Interactive dashboard for monitoring developments
* Fast search and filtering of historical incidents
* Automated alerts for major regional changes
* Clean and responsive UI

## How It Works

1. The platform continuously gathers data from publicly available news and information sources.
2. AI models analyze headlines, articles, and updates to identify relevant geopolitical events.
3. Events are categorized based on severity, location, and potential escalation risk.
4. The system generates concise summaries and visual timelines for easier monitoring.
5. Users can explore developments through an intuitive dashboard.
